# 划词助手「智能朗读」PRD

## 1. 文档信息

- 文档状态：Draft
- 版本：0.1
- 日期：2026-07-30
- 产品模块：划词助手 / 本地语音
- 目标版本：v0.6.x 起分阶段交付

## 2. 背景与目标

当前应用已经支持选中文本后使用 Windows 本地语音朗读。下一步不应只把朗读当作一个独立动作，而应将它嵌入“解释、翻译、术语学习和多轮问答”的阅读流程，让用户在看到需要听读的内容时立即播放。当前版本已经落地结构化朗读片段、翻译双语区域和问答选区朗读；应用更新则由独立的应用生命周期模块负责。

目标：

1. 降低语言学习、阅读和校对场景中的发音操作成本。
2. 让朗读对象从“整段选中文本”扩展到“术语、单词、句子、翻译结果和回答片段”。
3. 默认使用 Windows 本地语音，不上传用户文本，不依赖大模型。
4. 保持界面轻量：只有可朗读内容显示喇叭图标，不增加大面积按钮和复杂播放器。

## 3. 产品定位

「看到即能听」的本地阅读辅助能力：用户在任何划词结果中遇到不会读、想对比发音或需要连续听读的内容，都可以在当前位置完成播放。

## 4. 适用场景

| 场景 | 用户动作 | 朗读对象 | 优先级 |
| --- | --- | --- | --- |
| 独立划词 | 选中文本，点击“朗读” | 选中文本 | P0 |
| 解释单词 | 解释结果中出现单词和音标 | 单词、词组，不朗读音标符号 | P0 |
| 术语解释 | 点击术语卡片中的喇叭 | 术语名称、例句 | P0 |
| 翻译阅读 | 点击译文段落的喇叭 | 当前段落或句子 | P1 |
| 双语对照 | 分别播放原文和译文 | 原文、译文 | P1 |
| 多轮问答 | 播放最近回答或选中回答片段 | 回答中的纯文本 | P1 |
| 反向翻译 | 对比播放译文和回译文本 | 两个结果区域 | P1 |
| 文章阅读 | 连续播放多个段落 | 当前结果中的多个段落 | P2 |
| OCR 内容 | 图片/PDF 无法直接选择时播放 OCR 文本 | OCR 结果 | P2 |
| 代码阅读 | 播放注释或自然语言说明 | 注释和说明，不朗读代码符号 | P2 |
| 会话历史 | 重新打开历史结果后再次播放 | 选中文本或回答 | P2 |

## 5. 核心用户流程

### 5.1 解释结果中的音标

1. 用户选中英文单词，点击“解释”。
2. 结果页显示单词、词性、音标、定义、例句。
3. 单词标题或音标旁显示喇叭图标。
4. 用户点击后只朗读单词，不把 `/ˈ.../` 等音标字符直接读出来。
5. 播放中图标变为停止或播放中状态，再次点击停止。

### 5.2 翻译结果朗读

1. 用户选中文本并执行“翻译”。
2. 原文和译文区域分别提供“朗读本段”。
3. 系统根据区域语言选择语音；选择失败时回退系统默认语音。
4. 用户可在设置中调整语速，不需要重新请求模型。

### 5.3 问答结果朗读

1. 用户在多轮问答中点击回答旁的喇叭图标。
2. 默认朗读当前回答的纯文本内容。
3. 用户拖选回答中的一小段时，优先提供“朗读选中内容”。
4. 开始新一轮回答或关闭窗口时停止当前播放。

## 6. 功能需求

### 6.1 朗读入口

- 工具栏保留独立“朗读”动作。
- 解释结果：术语、单词标题和例句提供行内喇叭按钮。
- 翻译结果：原文、译文至少提供段落级朗读按钮。
- 问答结果：回答提供“朗读本回答”，选中回答文本后提供“朗读选中内容”。
- 只有存在有效朗读文本时才显示按钮。
- 图标按钮必须提供中文 `title` 和无障碍名称。

### 6.2 播放状态

- 空闲：喇叭图标。
- 启动中：短暂显示加载状态，避免用户重复点击。
- 播放中：显示停止或播放中图标。
- 已停止：恢复喇叭图标。
- 失败：显示短暂错误提示，并提供“打开语音设置”入口。
- 全局同一时间只播放一段文本；新播放自动停止旧播放。

### 6.3 文本处理

- 朗读前移除 Markdown 标记、代码围栏、链接 URL、表格分隔符和多余空白。
- 解释场景不直接朗读音标符号、JSON 标记或格式控制字符。
- 长文本按段落或句子拆分，不允许一次性阻塞整个结果窗口。
- 单段设置字符上限，超过上限提示用户改为朗读选中内容或分段播放。
- 朗读文本只在本地进程间传递，不发送到模型服务。

### 6.4 语言与语音

- 默认自动识别：包含中文字符时优先 `zh-CN`，否则优先 `en-US`。
- 自动识别失败时使用 Windows 默认语音。
- 设置页提供语速：慢速、标准、快速；后续可扩展精确滑块。
- 设置页展示系统已安装语音；没有目标语言语音时明确提示回退结果。
- MVP 不引入云端语音，不保存音频文件。

### 6.5 键盘与可访问性

- 朗读按钮支持 `Enter` 和 `Space`。
- 播放中可用 `Esc` 停止当前朗读。
- 图标必须有 `aria-label`、状态变化和键盘焦点样式。
- 不依赖颜色区分播放状态，同时提供图标变化或状态文字。

## 7. 音标与结果结构设计

### 7.1 不建议只靠正则识别音标

仅通过正则匹配 `/.../`、`[...]` 容易把路径、日期、代码和普通标点误判为音标。建议让解释动作逐步输出可识别的结构化片段：

```ts
interface SpeechSegment {
  id: string
  text: string
  language?: 'zh-CN' | 'en-US' | 'ja-JP' | 'ko-KR' | 'other'
  kind: 'term' | 'sentence' | 'paragraph' | 'answer'
}
```

渲染层根据 `SpeechSegment` 显示按钮，朗读时使用 `text`，而不是直接朗读完整 Markdown。每个片段还带有 `id`、`kind`、`label` 和可选语言标识，便于区分原文、译文、回译、回答和选中片段。过渡阶段可以对解释结果做保守识别，但必须允许用户手动选择文本朗读。

### 7.2 翻译与问答结果结构

- 翻译结果将原文、译文和语言标签分开显示；原文区域使用源文本检测出的语言，译文区域使用设置中的目标语言。
- 反向翻译要求模型使用“译文”“回译”“差异说明”标题，界面按标题拆成独立区域；无法识别标题时保留为单独译文区域，不丢失内容。
- 问答回答的正文支持鼠标或键盘选区，选中助手消息中的文本后显示“朗读选中内容”，只将选区文本传给本地语音服务。

### 7.2 推荐的结果按钮位置

- 单词标题：标题右侧，最优先。
- 音标：音标右侧，可与单词按钮合并，避免两个相同图标。
- 例句：句子右侧，仅在悬停或聚焦时显示。
- 段落：段落操作区右侧，不在正文中插入大按钮。
- 回答：回答卡片顶部或底部操作栏，与复制按钮并列。

## 8. 设置项

### MVP

- 启用本地朗读。
- 自动选择语言 / 使用系统默认语音。
- 朗读速度：慢、标准、快。
- 朗读时新选区是否自动停止：默认开启。

### 后续版本

- 按语言选择具体语音。
- 音量、音调和句间停顿。
- 朗读完成后自动播放下一段。
- 重复播放次数。
- 跟读模式：播放一句后暂停，等待用户复述。

## 9. 版本规划

### P0：嵌入核心阅读流

- 独立“朗读”动作。
- 解释结果中的术语/单词行内朗读。
- 术语解释和例句朗读。
- 统一播放状态、停止旧播放、中文和英文语音回退。
- 设置语速和本地语音开关。

### P1：覆盖翻译与问答

- 原文/译文段落级朗读。
- 问答回答级和选中片段朗读。
- 反向翻译双区域朗读。
- 朗读文本清洗和段落队列。

### P2：学习与长文能力

- OCR 结果朗读。
- 连续阅读、播放队列和断点续播。
- 跟读、重复播放和发音练习。
- 可选云端高质量语音，但必须显式开启并提示文本会离开本机。

## 10. 非功能需求

- Windows 10/11 可用，优先适配系统已安装语音。
- 点击后 300 ms 内进入播放中状态；语音进程启动失败不阻塞主窗口。
- 朗读失败不影响划词、AI 请求和结果窗口。
- 不把选中文本写入持久化设置、会话历史或日志。
- 420px 结果窗口、680px 设置窗口和 200% DPI 下不产生横向溢出。
- 长文本播放期间可以停止、关闭窗口或重新划词。

## 11. 验收标准

1. 解释英文单词时，单词标题旁可点击喇叭并正确朗读单词。
2. 音标字符不会被当成普通文本逐字朗读。
3. 翻译原文和译文可分别播放，语言选择错误时能回退系统默认语音。
4. 新选中文字后，上一段朗读会停止。
5. 朗读动作不会产生 AI 请求、API 费用或网络流量。
6. 没有可用系统语音时，界面给出可理解的错误和设置入口。
7. 播放、停止、键盘操作、焦点和 Tooltip 在浅色/深色主题下均可用。
8. 自动化测试覆盖动作迁移、文本清洗、语言识别、AI 隔离和播放状态。

只记录不包含用户文本的本地统计或匿名汇总：

- 朗读动作使用率。
- 解释结果行内朗读点击率。
- 翻译/问答朗读使用率。

## 13. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 系统没有目标语言语音 | 无法按预期发音 | 展示已安装语音，回退默认语音并给出设置入口 |
| Markdown/音标解析误判 | 朗读内容异常 | 优先结构化片段，正则识别仅作保守兜底 |
| 长文本播放时间过长 | 用户失去控制感 | 分段、队列、停止和字符上限 |
| 多窗口同时播放 | 声音重叠 | 主进程维护单一 SpeechService |
| 用户担心隐私 | 功能使用率下降 | 默认本地处理，不落盘、不联网，设置页明确说明 |
| PowerShell 被安全策略拦截 | 朗读不可用 | 提供语音不可用提示，后续评估 WinRT/SAPI 原生封装 |

## 14. 推荐实现顺序

1. 抽象主进程 `SpeechService` 的 `speak/stop/status` 接口。
2. 将解释结果中的术语和例句转换为可朗读片段。
3. 在结果组件增加可复用 `SpeechButton`。
4. 加入翻译、问答和反向翻译的段落级入口。
5. 增加设置项、语音列表、播放队列和完整无障碍状态。
